# Relatório do Projeto – TechStore BI

## 1. Introdução

O projeto TechStore BI foi desenvolvido com o objetivo de analisar os dados comerciais de uma empresa fictícia do setor de tecnologia, utilizando técnicas de Business Intelligence (BI).

A solução permite transformar dados de vendas em informações relevantes para apoiar a tomada de decisões.

## 2. Objetivos do projeto

- Analisar o faturamento e o lucro da empresa.
- Identificar os produtos mais vendidos.
- Avaliar o desempenho dos vendedores.
- Analisar os resultados por categoria e estado.
- Identificar os principais clientes.
- Desenvolver um dashboard interativo.

## 3. Tecnologias utilizadas

- Python: processamento e análise dos dados.
- SQL: consultas e extração de informações.
- SQLite: armazenamento dos dados.
- Pandas: manipulação dos dados.
- Matplotlib: criação de gráficos.
- Streamlit: desenvolvimento do dashboard.
- Visual Studio Code: ambiente de desenvolvimento.

## 4. Desenvolvimento

O projeto foi organizado em etapas:

### 4.1 Geração e preparação dos dados

Foram utilizados scripts Python para geração, validação e preparação dos dados comerciais.

### 4.2 Processo ETL

O processo ETL foi utilizado para organizar e preparar os dados antes de sua utilização nas análises.

ETL significa:

- Extract: extração dos dados.
- Transform: transformação e preparação.
- Load: carregamento dos dados no banco de dados.

### 4.3 Banco de dados

Foi utilizado SQLite para armazenar as informações da empresa, incluindo clientes, produtos, vendedores, vendas e itens de venda.

### 4.4 Consultas SQL

Foram desenvolvidas nove consultas principais para analisar os indicadores comerciais e identificar padrões de desempenho.

### 4.5 Visualização dos dados

Foram desenvolvidos gráficos utilizando Python e um dashboard interativo com Streamlit.

O dashboard possui filtros por período, categoria e estado, permitindo diferentes perspectivas de análise.

## 5. Resultados obtidos

A análise apresentou os seguintes resultados:

- Faturamento total: R$ 47.914.220,00.
- Lucro total: R$ 16.297.255,00.
- Categoria de maior faturamento: Informática.
- Estado de maior faturamento: São Paulo.
- Produto de maior faturamento: Notebook Gamer.
- Vendedor de maior faturamento: Vendedor 1.
- Cliente de maior faturamento: Gabriel Almeida.

## 6. Conclusão

O desenvolvimento do TechStore BI permitiu aplicar conhecimentos de Python, SQL, banco de dados, ETL, análise de dados e visualização de informações.

O dashboard facilita a interpretação dos resultados comerciais por meio de indicadores e gráficos interativos.

O projeto demonstra a importância do Business Intelligence na transformação de dados em informações estratégicas para auxiliar a tomada de decisões empresariais.
